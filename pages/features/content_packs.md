# Content Packs

Content Packs add optional features and enhancements to gameplay.

## Packs

- **Server Reports**  
  Report abusive or problematic servers to the Cactus Team.

- **Redstone**  
  Expands redstone functionality.

- **Title Screen**  
  Replaces the Mojang title screen with a Cactus custom screen.

- **Social**  
  Global chat, friends, and invites.

- **World Hosting**  
  Host your singleplayer world and invite friends or other players.

- **Dark Mode**  
  Applies a dark theme to the UI.

- **Server Widget**  
  Shows a server preview on the server list screen.

- **Customize**  
  Adds advanced UI customization options.

- **Head Database**  
  Adds custom heads to the creative menu.

## Management

Content packs can be enabled or disabled by moving them between the **Available** and **Selected** categories.
