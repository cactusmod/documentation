# Commands

### Cactus mod has commands that modify the game. All commands are prefixed with a #.

> Use `#help` to see all available commands at any time!

| Command           | Description                                                                     | Arguments                                                               |
| ----------------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **autocraft**     |                                                                                 | minecraft:item[quantity]                                                |
| **binds**         | Manage key bindings                                                             | clear, "bindname"                                                       |
| **capes**         | Shows the cosmetic capes you have in Cactusmod                                  | list, set                                                               |
| **chat**          | Changes chat between irc to global                                              | global, irc                                                             |
| **color**         | Lets you set colors                                                             | set, speed, toggle                                                      |
| **content**       | Load or unload [content packs](https://docs.cactusmod.xyz/content)                                                    | enable, disable                                                         |
| **debug**         | Debugs various thinks ([capes](https://docs.cactusmod.xyz/features/online/cosmetics/), profiles, skin, teams, title screen content, etc.) | CAPE_MANAGER, PROFILE_CACHE, SKIN_TEX, TEAMS_DATA, TITLE_SCREEN_CONTENT |
| **filteritem**    | Shows the Itemfilter                                                            | item, hand                                                              |
| **help**          | Shows all available [commands](https://docs.cactusmod.xyz/features/commands)                                                    |  none                                                                       |
| **irc**           | Connects to an IRC server and sends messages through it                         | send, disconnect, connect, address                                      |
| **schematics**    | Load, save, and share building plans                                            | share                                                                   |
| **script**        | Executes scripts                                                                | load, run, unload                               |
| **waypoints**     | Create and configure waypoints in your Minecraft world                          | add, color, get, list, remove, teleport, toggle                         |
| **worldmanager**  |                                                                                 | prepare                                                                 |   
| **nbt**           | View or edit NBT data of an item in your hand                                   | none                                                                       |
| **packet-logger** | Logs network packets                                                            | start, staus, stop                                                      |
| **uuid**          | Shows the Unique User ID of selectet Player                                     | "player"                                                                |
| **tool**          |                                                                                 | bind, unbind                                                            |
